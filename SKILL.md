# AIGC Text Detector

Detects whether text is human-written or AI-generated using BERT (Chinese) and RoBERTa (English) models.

## Components

| Component                | Description    |
| ------------------------ | -------------- |
| `AigcDetectorSharp`      | CLI tool       |
| `AigcDetectorSharp.UI`   | Desktop/Web UI |
| `AigcDetectorSharp.Core` | Shared library |

## CLI Usage

```bash
# Detect Chinese text (default)
./AigcDetectorSharp "待检测的中文文本"

# Detect English text
./AigcDetectorSharp -m en "English text to detect"

# From file
./AigcDetectorSharp -f /path/to/file.txt
```

## Options

| Option       | Description                                  |
| ------------ | -------------------------------------------- |
| `-m zh`      | Chinese model (default)                      |
| `-m en`      | English model                                |
| `-f <file>`  | Read text from file (.txt, .md, .docx, .pdf) |
| `--echo`     | Echo source text                             |

## Output Format

```
<Label> <Probability>
```

- `Label`: `Human` or `AI`
- `Probability`: confidence (0.0–1.0)

## Notes

- Text > 512 tokens is automatically split into chunks
- Supports .txt, .md, .docx, .pdf files
- Runs locally, no data sent externally
- Server mode works in headless environments
- If you are using source code instead of binary, please use 'dotnet run --'
